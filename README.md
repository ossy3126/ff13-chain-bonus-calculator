# FF13 Chain Bonus Calculator

**FFXIII チェーンボーナス計算機** — ファイナルファンタジーXIII のバトルで、行動ごとにチェーンボーナス（ブレイクゲージ）がどれだけ上がるかを計算するブラウザツールです。

パーティ3人のATBにコマンドを並べると、1ターンの合計上昇量、ブレイクするタイミング、ブレイクまでに必要なターン数を表示します。召喚中とドライビングモードにも対応しています。

---

## 主な機能

- **パーティ3人分の計算**
  - キャラ（ライトニング／サッズ／スノウ／ホープ／ヴァニラ／ファング）、ロール、ロールレベル、ATB本数をメンバーごとに設定できます。
  - 同じキャラは2人選べません。ほかのメンバーのキャラを選ぶと、設定ごと入れ替わります。
  - 2人パーティ、1人パーティにも対応しています。
- **全ロールのコマンド**（数値はバトルアルティマニアのアビリティリストと照合済み）
  - アタッカー、ブラスター、ディフェンダー、ジャマー、エンハンサー、ヒーラーのコマンドを収録しています。
  - キャラ専用コマンドは、そのキャラを選んだときだけ表示されます（シーンドライブ、デスペラード、ラストリゾート、ルーラーフィスト、ハイウィンド、デス、手投げ弾）。
- **キャラ固有の挙動**
  - ファングのたたかう：ATB4本以上のとき、最後の枠だけ連撃（0.0×2＋0.25×2）になります。
  - ファングのリベンジモード／チャージ：地上の敵には4回攻撃（0＋0＋0.25＋0.25）になります。
  - サッズのエリアブラスト：0.2×7ヒットです。当たったヒット数を指定でき、途中でブラスターにシフトした場合も計算できます。
  - ルーラーフィスト・ハイウィンド：攻撃後にチェーンボーナスを100.0%に戻します。
- **行動順の指定**
  - ATB欄でも結果の内訳でも、▲▼で並べ替えられます。
  - ブレイクのタイミングや、弱体・ウィークが入るタイミングが計算に反映されます。
- **敵の状態**
  - チェーン耐性、ブレイク値、物理／魔法耐性、属性耐性（6属性）を設定できます。
  - 弱体数（挑発も含む）、ウィーク、ブレイク中、打ち上げも設定できます。
- **チェーンの開始**
  - チェーンが途切れた状態（画面左上のCHAINが0.0）から始めると、最初の1ヒットは持続を始めるだけで%は上がりません。
  - 持続0秒の技（ブレイク前のシーンドライブなど）は、チェーンが途切れているとまったく上がりません。
- **召喚中・ドライビングモード**
  - 召喚獣6体（オーディン、シヴァ、ブリュンヒルデ、バハムート、アレキサンダー、ヘカトンケイル）に対応しています。
  - 召喚獣の初期の行動は、バトルアルティマニアの「通常の行動」に合わせています。
  - ドライビングゲージの消費（残り2以上ならどの技も使え、残り1で止まる）と、フィニッシュ技のレベル別加算も計算します。
- **ターンの引き継ぎ**
  - 終了時のチェーン、ブレイク状態、弱体、各キャラの最後の行動を次のターンに引き継げます。
- **TPアビリティ**：クエイク（上昇10.0）に対応しています。

## 使い方

1. 一番上で「通常バトル／召喚中／ドライビングモード」を選びます。
2. 「パーティ」のタブで、メンバーごとにキャラ・ロール・ATBなどを設定し、コマンドのボタンを押してATBに並べます。
3. 「敵の状態」に、チェーン耐性・ブレイク値・属性耐性などを入れます。
4. 「ゲージ」で、現在のチェーンボーナスと、チェーンが途切れた状態から始めるかどうかを設定します。
5. 右側に、合計上昇量、ゲージ、行動ごとの内訳が出ます。内訳の行をタップすると、補正の詳細が見られます。
6. 次のターンを計算するときは、「この結果を引き継いで次のターンへ」を押します。

> ドライビングモードの召喚獣に付くブラスターのボーナスは、「通常バトル」のメンバー設定から計算します。召喚したときのパーティを設定しておいてください。

## 計算式

```
1ヒットの上昇量 = { (基本上昇量 + 基本上昇量への補正) × チェーン耐性による補正 + バトルの状況による補正 } × 属性への耐性による補正
```

| 項目 | 内容 |
|---|---|
| 基本上昇量への補正 | ブラスターのロールボーナス（自分 +1.0〜3.0／ほかのブラスターから +0.1〜0.3）、ジョイントレイド、ハイテンション、ブレイクチェーン、チェーンボーナスUP／UP改 |
| チェーン耐性による補正 | (100 − チェーン耐性) ÷ 100 |
| バトルの状況による補正 | 違うコマンド、弱点、HP、強化・弱体の数、ATBの先頭のコマンド、ブレイク予兆など（ロールごと） |
| 属性への耐性による補正 | 吸収・無効 ×1/4／耐久・半減 ×1/2／標準・弱点 ×1（弱点は状況の補正が付く） |
| ブレイク | ブレイクした瞬間に +100%。ブレイク中はチェーン耐性が 0 |
| ブレイク予兆 | ブレイク値まで上げるのに必要な上昇量の 0.90〜0.92 倍 |

掛け算のたびに小数第3位以下を切り捨てます。
