# FF13 Chain Bonus Calculator

**FFXIII チェーンボーナス計算機** — ファイナルファンタジーXIII のバトルで、行動ごとにチェーンボーナス（ブレイクゲージ）がどれだけ上がるかを計算するブラウザツールです。

パーティ3人のATBにコマンドを並べると、1ターンの合計上昇量、ブレイクするタイミング、ブレイクまでに必要なターン数を表示します。召喚中とドライビングモードにも対応しています。攻撃力と敵の最大HPを入れると、行動ごとのダメージと残りHP、撃破のタイミングも計算します。

### チェーンボーナスだけ知りたいときに必要な入力

- 戦闘モード（通常バトル／召喚中／ドライビングモード）
- 各メンバーのキャラ、ロール、ロールレベル（ブラスター／アタッカー）、ATBゲージ数、HP、コマンド、ロールのアビリティ（ブレイクチェーン、ジョイントレイド、ハイテンション）
- 敵のチェーン耐性、ブレイク値、物理耐性、魔法耐性、属性耐性
- 現在のチェーンボーナス

「ダメージ用」の項目（攻撃力と攻撃側の補正）、敵の最大HP、召喚獣ランクは、ダメージと残りHPを出したいときだけ入力します。

## 主な機能

- **パーティ3人分の計算**
  - キャラ（ライトニング／サッズ／スノウ／ホープ／ヴァニラ／ファング）、ロール、ロールレベル、ATB本数をメンバーごとに設定できます。
  - 同じキャラは2人選べません。ほかのメンバーのキャラを選ぶと、設定ごと入れ替わります。
  - 2人パーティ、1人パーティにも対応しています。「パーティの人数」を選ぶと、メンバー1から順にその人数がパーティに入り、オプティマの一覧もその人数用になります。
  - 戦闘不能になるタイミング（内訳の何番目の行動の後か）をメンバーごとに指定できます。倒れたメンバーはその後行動せず、ジョイントレイドの人数やブラスターのパーティボーナスからも外れます。
- **全ロールのコマンド**（数値はバトルアルティマニアのアビリティリストと照合済み）
  - アタッカー、ブラスター、ディフェンダー、ジャマー、エンハンサー、ヒーラーのコマンドを収録しています。
  - キャラ専用コマンドは、そのキャラを選んだときだけ表示されます（シーンドライブ、デスペラード、ラストリゾート、ルーラーフィスト、ハイウィンド、デス、手投げ弾）。
  - そのキャラが覚えないコマンドは表示されません。
  - コマンドは「全／属性なし／火／氷／雷／水／風」のボタンで絞り込めます。「全」は使えるコマンドを属性ごとの見出しつきですべて表示します。覚えるコマンドがない属性のボタンは表示されません（例：サッズは氷・水なし）。
- **キャラ固有の挙動**
  - ファングのたたかう：ATB4本以上のとき、最後の枠だけ連撃（0.0×2＋0.25×2）になります。
  - ファングのリベンジモード／チャージ：地上の敵には4回攻撃（0＋0＋0.25＋0.25）になります。
  - サッズのエリアブラスト：0.2×7ヒットです。当たったヒット数を指定でき、途中でブラスターにシフトした場合も計算できます。
  - ルーラーフィスト・ハイウィンド：攻撃後にチェーンボーナスを100.0%に戻します。
- **行動順の指定**
  - 「交互（1人1コマンドずつ）」と「メンバーごとにまとめて」のそれぞれで、M1〜M3の順番を全6通りから選べます。
  - 「自分で並べる」では、ATB欄でも結果の内訳でも、▲▼で並べ替えられます。
  - ブレイクのタイミングや、弱体・ウィークが入るタイミングが計算に反映されます。
- **オプティマの選択**
  - 「よく使うオプティマ」（3人用17個・2人用9個）と、ゲームのすべてのオプティマから選べます。オプティマ名を選んだあと、「誰がどのロールか」を選びます（例：ラッシュアサルトなら、アタッカーがメンバー1・2・3のどれか）。
  - 「今のオプティマ」を選ぶと3人のロールがまとめて変わり、「オプティマチェンジ先」を選ぶと3人のチェンジ後のロールがまとめて入ります。
- **オプティマの登録**
  - 「誰がどのロールか」まで決めた並びを登録しておくと、選ぶだけで1回で3人のロールが入ります（よく使うオプティマ・すべてのオプティマは、名前のあとに並びも選ぶので2回）。
  - 名前はロールの組み合わせからゲームのオプティマ名が自動で入ります。登録はブラウザに保存されます。
- **オプティマチェンジ**
  - 「全員の行動が当たってからチェンジ」を選ぶと、このターンはそのまま計算し、「次のターンへ」で選んだオプティマに切り替わります。
  - 「内訳の○番目の行動のあと」にオプティマを変えたときの計算ができます。メンバーごとに「チェンジ後のロール」を選びます。
  - チェンジの時点で行動が決まっていた（動き出していた）メンバーのATBの行動は最後まで出て、決まっていなかったメンバーの行動は取り消しになります（メンバーごとに「自動／行動決定済み／未決定」を選べます）。
  - 最後まで出た行動のうち、チェンジ後に当たるヒットは、そのときのロールでロールボーナス・条件補正・ジョイントレイドの人数を計算します（実測で確認）。
  - 複数ヒットの技（シーンドライブ、デスペラード、ラストリゾートなど）は、ATBの行で「○hit目から（変更後のロール）」を指定すると、技の途中でロールが変わった場合も計算できます。
  - 1ヒットの技（デスなど）は、ATBの行で「当たる時のロール」を選ぶと、当たる直前にオプティマを変えた場合を計算できます。
- **ブレイク早見表**
  - 今のコマンドの並びのまま、ターン開始時のチェーンボーナス（画面の表示）ごとに、誰の何発目でブレイクするかと、オプティマを変えるタイミングの目安を一覧にします。
  - 画面の表示は小数第1位までの切り捨てなので、表示だけでは結果が決まらない値は両方を出します。
  - 「次のターンへ」で引き継ぐときは、内部の値（小数第2位まで）のまま計算します。
- **敵の状態**
  - チェーン耐性、ブレイク値、物理／魔法耐性、属性耐性（6属性）を設定できます。
  - 弱体数（挑発も含む）、ウィーク、ブレイク中、打ち上げも設定できます。
  - 付与済みの弱体が切れてから付け直した場合は「切れて付け直し」にチェックすると、成功ボーナス（+5.0）がもう一度付きます。
- **敵の登録**
  - 1〜13章の敵（289体）が最初から入っています。章ごと（11章は地域・ミッションごと）に並び、一覧の検索欄で名前から探せます（ひらがな・英語名でも可）。
  - 敵を選ぶと耐性などがまとめて入り、その章のパーティとロールの制限もかかります（→[章ごとのパーティとロール](#章ごとのパーティとロール)）。
  - 戦闘中に値が変わる敵は、状態ごとに分けて入っています。ターンの途中でブレイクすると、ブレイク後の耐性に自動で切り替えて計算します（→[状態で値が変わる敵](#状態で値が変わる敵)）。
  - 立ち上がり・リミッター解除・形態変化は、敵の説明の下のボタンで次の状態に切り替えられます。HP全回復やチェーンボーナスのリセットも一緒に入ります。
  - ガードを使う敵（シド・レインズ、PSICOM強襲兵、聖府親衛猟兵）は、「ガード中」にチェックすると受けるダメージを90%減らして計算します。
  - 自分で敵を登録・上書き・削除することもできます（ブラウザに保存）。
- **チェーンの開始**
  - チェーンが途切れた状態（チェーンゲージが空）から始めると、最初の1ヒットは持続を始めるだけで%は上がりません。
  - 持続0秒の技（ブレイク前のシーンドライブなど）は、チェーンが途切れているとまったく上がりません。
- **召喚中・ドライビングモード**
  - 召喚獣6体（オーディン、シヴァ、ブリュンヒルデ、バハムート、アレキサンダー、ヘカトンケイル）に対応しています。
  - 召喚獣の初期の行動は、バトルアルティマニアの「通常の行動」に合わせています。
  - ドライビングゲージの消費（残り2以上ならどの技も使え、残り1で止まる）も計算します。
  - 召喚獣には、パーティのブラスターのロールボーナスやジョイントレイドは付きません（召喚中のメンバーのジョイントレイドでは、召喚獣も人数に数えます）。
  - ドライビングモードの技の条件補正（ブレイク中・打ち上げ・ブレイク予兆）は、バトルアルティマニアの値の2倍です（弱点は本どおり +0.1）。
  - フィニッシュ技のダメージ前の上昇は、細かいヒットの連続として、1回ずつチェーン耐性と条件補正（本の値のまま）を受けます（ダイヤモンドダスト・斬鉄剣・ガイアサルヴォー。実測で確認）。ムスペルフレイム・メガフレア・聖なる審判は未確認のため、本の値をそのまま加算します。
- **2章まで（オプティマ解禁前）**
  - 「2章まで（オプティマ解禁前）で計算する」にチェックを入れると、ロールなしで計算します。
  - メンバー1はリーダー（ライトニング／スノウ／ヴァニラ）、メンバー2・3はAIで、リーダーで決まります（ライトニング＋サッズ（ライトニング1人はなし。1度だけスノウも入る3人パーティあり）／スノウ＋ガドー（＋レブロ）。スノウのパーティはスノウ1人・スノウとガドー・3人のどれか／ヴァニラ＋ホープの2人だけ）。リーダーを変えると、AIメンバーとパーティの人数が自動で合わせられます。ファングは登場しないので選べません。
  - 使えるコマンドは、ライトニング：たたかう・エリアブラスト、スノウ：たたかう・手投げ弾、ほかのキャラ：たたかうです。ガドーのたたかうは2.0×7ヒット（ATB3）、レブロは6.0×1ヒット（ATB2）、ほかは0.5です（バトルアルティマニア）。
  - ATBはキャラで決まります（ヴァニラ3、ガドー・レブロ3.5、ほかは2）。
  - 1ヒットごとの上昇は「チェーンボーナス×(100−チェーン耐性)/100」だけで、ロールのボーナスや条件補正はありません。AIメンバーは、ターンの1つ目のコマンドの全ヒットに+0.2、HPが満タンならさらに+0.3が付きます。リーダーには付きません（ゲパルト烈爪・ベヒーモス改で実測）。
  - ブレイク値ちょうどではブレイクせず、超えたヒットでブレイクします（実測）。
  - ダメージの計算は対象外です。
- **ターンの引き継ぎ**
  - 終了時のチェーン、ブレイク状態、弱体、各キャラの最後の行動、戦闘不能、敵の残りHPを次のターンに引き継げます。
- **TPアビリティ**：クエイク（上昇10.0）に対応しています。
- **入力の自動保存**
  - 入力した内容（モード、パーティ、ATBのコマンド、行動の順番、敵の状態、ゲージ、欄の開閉など）はブラウザに自動で保存され、次に開いたときもそのまま残ります。
  - 「入力を初期値に戻す」を2回押すと、最初の状態に戻ります。登録したオプティマと敵は消えません。
- **ダメージと残りHP**（任意）
  - ダメージ用の欄（メンバーの攻撃力・補正、敵の最大HP・残りHP・見積もり）は、たたんだ状態で始まります。見出しを押すと開きます。入力があると見出しに「入力あり」と出ます。
  - 各メンバーの物理攻撃力・魔法攻撃力と、攻撃側の補正（ブレイブ／フェイス系、ハイボルテージ、ピンチにパワフル、仲間戦闘不能で強化、元気だと／危機だと威力UP、属性ダメージ+○%、攻撃力ダウン装備、エン系、チェーンスターター・ゾーンクラッシュ・バックスタブ・インパクトブレイク／ブレイクバースト、エンドストライク）を入れられます。
  - ダメージは、そのヒットの時点のチェーンボーナスで計算します。アタッカーのロールボーナス、物理/魔法耐性・属性耐性、デプロテ／デシェル、ウィークも反映します。
  - 召喚獣のダメージは、召喚獣ランクから攻撃力を決めます。
  - 敵の最大HPを入れると、行動ごとの残りHPと撃破した行動を表示し、次のターンにも残りHPを引き継ぎます。
  - 斬鉄剣は、その時点の残りHPが「3.0×オーディンの物理攻撃力×チェーンボーナスの2乗」未満なら一撃で倒せると判定します。チェーンボーナスは、斬鉄剣のヒット自身の上昇まで含めた値です（実測で確認）。

## 状態で値が変わる敵

一覧では状態ごとに並んでいて、敵の説明に切り替わるきっかけを書いています。「ブレイクで自動」の敵は、ターンの途中でブレイクすると、ブレイク後の耐性に切り替えて計算します。

| 種類 | 敵 | 変わるところ |
|---|---|---|
| ブレイクで自動 | バルバロイ、スケイルビースト、シルトパット月光・陽炎、イェニチェリ、ランドガレオン、マムルーク、クシャトリヤ、アタナトイ、グランガッチ、オーファン（第二形態） | ブレイク時は物理・魔法や属性の耐性が下がる |
| ブレイクで自動 | 戦闘爆撃騎カルラ（2回目）、ラクタヴィージャ、ヴェーターラ、守護騎アナヴァタプタ | バリア・無敵がブレイクで消える |
| ブレイクで自動 | ファルシ=ダハーカ | 技ごとに属性が変わり、倒れこむと全属性標準 |
| 立ち上がり | ベヒーモス魁星、キングベヒーモス、カイザーベヒーモス、ベヒーモス零式 | チェーン耐性・HP・物理/魔法耐性（HP全回復やチェーンボーナスのリセットあり） |
| 構え・形態 | 快速機シュトルヒ・ミーラン・ファルケ・アドラー、決戦騎ティアマット、プラウド・クラッド（2回目）、侵攻制圧騎ウシュムガル（1回目） | 構え中・形態・リミッター解除後でチェーン耐性や耐性が変わる |
| モード | 試作騎ユイジンシャン、防衛騎スウェリエン | モードごとに属性の弱点・吸収・無効が変わる |
| その他 | ウェルキンゲトリクス（バリア中はすべて無効）、シド・レインズ（シフトで物理・魔法耐性）、飛空戦車グライフ（主砲の出現前後）、バルトアンデルス（パーツの消滅前後）、アダマンタイマイ・アダマントータス・ロングイ（倒れこみ時） | |

ウシュムガル（1回目）のオーバードライブ後と、プラウド・クラッド（2回目）のリミッター解除後は、自分にかけたデプロテ・デシェルを最初からかかっている弱体として計算し、弱体数にも数えます。

### 敵データについて

- 値は『ファイナルファンタジーXIII バトルアルティマニア』を参照しています（HP・チェーン耐性・ブレイク値・物理/魔法耐性・属性耐性、状態ごとの値）。
- 名前は日本語版の名前です（Final Fantasy Wiki の「Final Fantasy XIII translations」の対訳表による）。同じ名前の敵は「（1回目）」「（2回目）」のように戦う順で区別しています。
- 飛空戦車グライフは、パーツを1個倒すごとに本体に88,200ダメージが入り、4個倒してHP73,500以下になると主砲が出現します。

## 使い方

1. 一番上で「通常バトル／召喚中／ドライビングモード」を選びます。
2. 「パーティ」のタブで、メンバーごとにキャラ・ロール・ATBなどを設定し、コマンドのボタンを押してATBに並べます。属性のボタンでコマンドを絞り込めます。
3. 「行動の順番」で、交互／まとめて（それぞれ6通り）か、自分で並べるかを選びます。
4. 「敵の状態」に、チェーン耐性・ブレイク値・属性耐性などを入れます。
5. 「ゲージ」で、現在のチェーンボーナスとブレイク値を入れます。現在のチェーンボーナスが100.0%なら「チェーンゲージが空の状態から始める」に自動でチェックが入り、100%より上なら外れます（100.0%でもチェーンが続いている場合だけ、手でチェックを外してください）。
6. 右側に、合計上昇量、ゲージ、行動ごとの内訳が出ます。内訳の行をタップすると、補正の詳細が見られます。
7. 次のターンを計算するときは、「この結果を引き継いで次のターンへ」を押します。

## 計算式

```
1ヒットの上昇量 = { (基本上昇量 + 基本上昇量への補正) × チェーン耐性による補正 + バトルの状況による補正 } × 属性への耐性による補正
```

| 項目 | 内容 |
|---|---|
| 基本上昇量への補正 | ブラスターのロールボーナス（自分 +1.0〜3.0／ほかのブラスターから +0.1〜0.3。受け取る側もブラスターのときだけ）、ジョイントレイド、ハイテンション、ブレイクチェーン、チェーンボーナスUP／UP改 |
| チェーン耐性による補正 | (100 − チェーン耐性) ÷ 100 |
| バトルの状況による補正 | 違うコマンド、弱点、HP、強化・弱体の数、ATBの先頭のコマンド、ブレイク予兆など（ロールごと） |
| 属性への耐性による補正 | 吸収・無効 ×1/4／耐久・半減 ×1/2／標準・弱点 ×1（弱点は状況の補正が付く） |
| ブレイク | ブレイクした瞬間に +100%。ブレイク中はチェーン耐性が 0 |
| ブレイク予兆 | ブレイク値まで上げるのに必要な上昇量の 0.90〜0.92 倍 |
| 弱点 | 物理/魔法耐性と属性耐性を掛け合わせたダメージ倍率が1倍を超えるとき |
| フィニッシュ技 | ダメージ前の上昇は連続ヒット（例：斬鉄剣Lv3は 17.0×7回 → 攻撃24.0） |

チェーンボーナスの上昇量は、掛け算のたびに小数第3位以下を切り捨てます。

ダメージは、攻撃力 × 技の倍率 × (1 + 攻撃力アップ%) × ブレイブ／フェイス × ばらつき × チェーンボーナス × (1 + ダメージ補正%) × 耐性 で計算します（上限 99,999、限界突破・召喚獣は 999,999）。
